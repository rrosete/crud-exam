# Asialink.ai Exam - Simple CRUD Application

** A simple CRUD (Create, Read, Update, Delete) REST API built with Next.Js**

---

## Project Structure

src/  
├── app/ # Contains main application files.

├──global.css / # global Styles.

├── components/ # Contains reusable components.

├── constant/ # constant values used throughout the application.

├── modules/ # Contains different modules or features of the application.

## Tech Stack

- **Frontend**: NextJs
- **Css**: Tailwind Css

## Setup Prerequisites

- Next.Js (v15+)

## Installation

1. **Clone the repository**:

   ```bash
   git clone crud-exam
   cd crud-exam

   ```

2. **Install dependencies**:

   ```bash
   npm install or npm i

   ```

3. **Set up environment**: Copy '.env.sample' to '.env' and update database credentials:

   ```bash
   NEXT_PUBLIC_API_URL=


   ```

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
